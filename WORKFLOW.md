# Lecture-note production workflow

This independent study edition applies transcript-grounded-textbook, rigorous-explainer and science-editor using the completed IITM/NPTEL projects as the depth and reader reference. The source course is Computational Thermodynamics and Kinetics of Materials by Prof. K. Guruvidyathri, University of Hyderabad; IIT Madras coordinates NPTEL distribution.

1. Enumerate the complete playlist, including entries before the supplied starting index. Preserve the introduction separately from the sixty official lessons.
2. Acquire complete recording evidence with durations, digests and provenance. Unusable publisher caption metadata and rate-limited YouTube captions led to local small.en ASR. Recognition and chunk-boundary uncertainty remain.
3. Read every complete transcript sequentially, map topic spans and document consequential ambiguities. Transcript reading does not establish complete audiovisual or board-equation verification.
4. Calibrate a substantial pilot with definitions, assumptions, derivations, executable calculations, actual primary-source reading and complete worked solutions. Scale that depth to 24 original chapters rather than transcribing the recordings.
5. Obtain two independent scientific reviews from reviewers other than each chapter's author. Repair actual findings and bind accepted closures to the current raw body bytes. Retain earlier findings and repair history privately.
6. Assemble root-level chapters, metadata, the complete source map, references and an offline dark reader. Preserve accepted body bytes when updating shared navigation or status.
7. Execute every public chapter program, compare exact downloadable source and displayed output, verify all local links/timestamps/digests and inspect all public HTML at desktop and mobile widths.
8. Audit an explicit public-file inventory against an independent permitted-artifact grammar. Export only public committed Git bytes, install the pinned dependencies in a new project-local environment, run every documented script, rebuild all HTML byte-identically and repeat actual offline browser checks.
9. Commit and push the separate public course repository, deploy Pages, check the actual GitHub README preview and compare every served payload byte. Exclude only the publication report from its own hash list, then independently require that the served final report exists, parses, passes, binds the current payload and exactly matches local final bytes.
10. Promote completion only after complete course coverage, scientific acceptance and actual local/live checks. A push, a rendered page or a code assertion alone is not completion evidence.

All acquisition files, caches, environments, temporary files, reports and subprocess working directories stay inside this project. Browser checks are headless and do not take over the desktop. Raw media, transcripts, downloaded papers, prompts and private review reports are ignored and excluded from publication.

The public records distinguish scientific review from numerical consistency, source reading, reproducibility and publication verification. They disclose their scope instead of implying experimental validation or independent verification of unread source material.
